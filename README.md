## Hello — I'm Sina

I'm a backend developer from Tehran, focused on **Python, Django, REST APIs, and reliable server-side systems**. I enjoy owning the full path from data modeling and authentication to containerization, reverse proxies, HTTPS, and production troubleshooting.

My background in ISP technical support and robotics teaching shaped the way I work: understand the system, isolate the real problem, document the solution, and communicate it clearly.

- **Build:** REST APIs, authentication and authorization, RBAC, real-time features, caching, and background tasks
- **Operate:** Dockerized services on Linux with Nginx, DNS, HTTPS, CI/CD, and self-hosted infrastructure
- **Learn:** C#, ASP.NET Core, EF Core, testing, and maintainable software architecture

## Selected work

### 🩺 Medisite · Pediatric Clinic Platform

`Django REST Framework` `PostgreSQL` `JWT` `RBAC` `Docker`

A live pediatric clinic platform with patient registration, appointment scheduling, content management, and separate Doctor, Editor, and Patient roles. I built the backend, enforced domain rules, containerized the application, and deployed it on my Linux server.

[Live site ↗](https://dr-noohi.ir)

### 🛒 CommerceFlow API

`Django REST Framework` `PostgreSQL` `Redis` `Celery` `Pytest`

An e-commerce backend covering catalog, cart, checkout, and order workflows. It includes JWT authentication, role-based permissions, caching, background jobs, OpenAPI documentation, automated tests, Docker, and continuous integration.

[Source ↗](https://github.com/cnafateh/CommerceFlow-API)

### 💬 Private Real-Time Chat

`Django` `Channels` `ASGI` `WebSockets` `Docker`

A private messaging platform with authenticated real-time communication, persistent history, username-based user discovery, and timezone-aware messages—deployed behind a reverse proxy with secure WebSocket support.

[Source ↗](https://github.com/cnafateh/PrivateReal-timeChatPlatform) · [Live demo ↗](https://chat.sinafateh.ir)
